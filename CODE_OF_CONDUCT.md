# Code of conduct

PlainOntology follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work, and make it easy for newcomers to take part. Harassment and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

To report a problem, contact the maintainer privately through the email address on their GitHub profile, or use GitHub's "Report content" option. Reports are kept confidential.
